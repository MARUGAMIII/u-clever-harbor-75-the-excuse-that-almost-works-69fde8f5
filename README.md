One line a gamer texts the boss to skip work on GTA 6 launch week, for make.fun's "The Excuse That Almost Works" bounty ($2 in USDC). The excuse is airtight — a cracked delivery and a courier collection that strands the sender at home all day — except for one word: "new". A brand-new monitor arriving the morning of launch week is exactly the purchase a gamer makes before a launch, so the manager almost believes it, and then, a beat too late, notices the timing.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
